# ERC Launcher 0.4.7

Ein Fehler, der nur bei anderen auffiel: Lobbys gingen nur auf Rechnern, die beim
Unterbau angemeldet waren.

## Änderungen

- Der Launcher reicht das Netplay-Kennzeichen jetzt **immer** an das Spiel weiter.
  Vorher hing es an der Anmeldung — wer nicht angemeldet war, startete ein Spiel,
  das auf keine Lobby hörte, und jeder Beitritt lief in eine Zeitüberschreitung.
- Die Meldungen sagen jetzt, was zu tun ist: F1 25 muss über **Play** in diesem
  Fenster gestartet werden, und es muss im Hauptmenü stehen.
