# ERC Launcher 0.4.3

Zwei Fenster auf demselben Rechner, die beide am Spiel schrauben, waren bisher
möglich. Jetzt nicht mehr.

## Änderungen

- Startet der Launcher und es läuft schon einer, beendet sich der zweite sofort.
- Das Installationsprogramm findet eine vorhandene Einrichtung über den Eintrag
  unter „Apps" und ersetzt sie am selben Ort. Die Verzeichnisauswahl entfällt dann —
  ein zweiter Ordner kann nicht entstehen.
- Läuft das Programm beim Installieren noch, fragt der Installer nach, statt eine
  offene Datei zu überschreiben. Beim stillen Aktualisieren wird nicht gefragt.
