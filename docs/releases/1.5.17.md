Was sich seit 1.5.16 geändert hat:

- **Der Beweislauf von 1.5.16 hat geliefert.** Der Host löst die Gastzeile der Punktestands-
  Auflösung auf ein echtes Element auf; der Gast crasht, weil dieselbe Liste bei ihm keinen
  Eintrag für den eigenen, noch fahrerlosen Spieler hat.
- **Der Gast bleibt jetzt im Raum.** Eine Teilnehmerzeile ohne Eintrag bekommt den Wert, den
  das Spiel für „keine Strafsumme" nutzt, statt zu crashen. Ob der Gast dann einen Fahrer
  wählen kann (oder eine leere Fahrerliste sieht), steht in den Protokollen.
- **Mehr Protokoll:** welche Kategoriewert-Option das Setup ohne eigene Wahl benutzt und welche
  Rolle die Session dabei hat (`setupFromUnranked without an addon category`).
- **Wichtig: alle im Raum brauchen diese Fassung.**
- Sonst wie 1.5.16: Unterbau 1.10.26, Direktweg bleibt bestehen.
