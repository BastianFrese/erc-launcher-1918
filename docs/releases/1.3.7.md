Was sich seit 1.3.6 geändert hat:

- **Beitreten in einen Raum läuft auf F1 25 Build 1.0.145.** Der Kern sucht die Funktion, die einem
  Spielmodus seinen Index gibt, jetzt auch mit dem Muster dieser Fassung. Abgelesen am entpackten
  Code der laufenden Installation, nicht geraten.
- Die Diagnose aus 1.3.6 bleibt: findet der Kern die Stelle auf einer künftigen Fassung wieder
  nicht, steht der Code-Ausschnitt im `loader.log`.
