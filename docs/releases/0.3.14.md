# Jeder kann hosten — ohne offenen Port

Eine Lobby läuft wahlweise über unseren Server. Wer hostet, bekommt einen Raumcode, die anderen tragen ihn ein.

## Änderungen

- Raumcode erzeugen, weitergeben, fertig — kein Port, keine Adresse
- Ohne Code geht es weiter direkt (dann muss der Port offen sein)
- Der Server reicht nur weiter, er speichert nichts
