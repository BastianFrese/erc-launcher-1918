# ERC Launcher 0.4.2

Der Launcher fragt jetzt beim Start unseren Server, ob es eine neue Fassung gibt.

## Änderungen

- Aktualisierung über `download.erdi-erc.de`: steht dort eine höhere Fassung, zeigt
  der Launcher in der Seitenleiste einen Knopf. Er lädt das Setup, prüft die
  SHA-256 und startet es; danach beendet er sich, damit der Installer die laufende
  Datei ersetzen kann.
- Stimmt die Prüfsumme nicht, wird nichts installiert und der Grund steht da.
