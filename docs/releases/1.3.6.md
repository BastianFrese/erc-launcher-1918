---

Diese Fassung ändert am Verhalten nichts. Sie hilft, den letzten Fehler zu finden:

- Findet der Kern auf einer F1-25-Fassung die Funktion nicht, die einem Spielmodus seinen Index
  gibt, schreibt er beim Start einen Ausschnitt des entpackten Codes ins `loader.log`
  (rund 2 KB, 16 Bytes je Zeile). Daraus lässt sich das fehlende Muster ablesen.
- Der Versatz wird aus einer benachbarten Funktion berechnet, die auf diesem Build bereits
  gefunden wird — geraten wird nichts.

Wer die Logs schickt, hilft damit direkt.
