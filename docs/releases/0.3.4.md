# Einwilligung: ein Klick genügt

Der Text bleibt gemerkt, und ein zweiter Klick auf „einverstanden“ stört nicht mehr.

## Änderungen

- Der Einwilligungstext kommt aus einer eigenen Ablage, wenn das Spiel ihn nicht mehr ausgibt
- Ist die Einwilligung schon erteilt, passiert beim Bestätigen nichts Falsches
- Meldet das Spiel die Einwilligung nicht an, steht sein eigener Bericht in der Meldung
