# Beim Beitreten zählen nur die Mods, die der Host fährt

Ausgeschaltete Mods beim Host sind kein Thema mehr — und Simplified ist nach dem ersten Start da.

## Änderungen

- Verglichen werden nur die eingeschalteten Mods des Hosts
- Was bei dir läuft und beim Host nicht, wird abgeschaltet
- Was beim Host aus ist, wird nicht heruntergeladen
- Simplified wird beim ersten Start einmalig geholt (rund 80 MB)
