Die erste fertige Fassung.

- **Zusammen fahren ist einfacher:** einer macht die Lobby auf, die anderen tippen den
  vierstelligen Code ein. Das läuft über unseren Server — kein Konto, kein offener Port.
- **Die Mods passen zusammen:** vor dem Beitreten prüft der Launcher, ob beide Seiten dieselben
  Mods haben, und sagt es dir, wenn etwas fehlt.
- **Neuer Ladebildschirm** beim Start einer Sitzung.
- **Hilfe-Seite** mit einem Weg, uns über Ko-fi zu unterstützen.
