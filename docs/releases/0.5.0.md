# ERC Launcher 0.5.0

Die Aktualisierung war bisher ein Installationsfenster mit drei Seiten. Jetzt ist
sie ein Klick.

## Änderungen

- Der Launcher spielt das Setup **still** ein (`/S`) und startet sich danach
  selbst neu. Der Rechner braucht dafür keine Hand mehr.
- Das Heruntergeladene wird weiterhin an der SHA-256 geprüft; stimmt sie nicht,
  passiert nichts und der Grund steht im Fenster.
