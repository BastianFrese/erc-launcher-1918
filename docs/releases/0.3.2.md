# Wenn der Start nicht geht, sagt der Launcher warum

Bisher konnte der Startknopf grau und stumm sein — jetzt öffnet sich die Einwilligung oder der Grund steht im Fenster.

## Änderungen

- Fehlt die Einwilligung für das modifizierte Spiel, öffnet sich das Fenster dazu
- Wer zustimmt, startet direkt — kein zweiter Klick nötig
- Ein gesperrter Startknopf sagt beim Drücken, was fehlt
