# Defender-Ausnahme auch nach einem stillen Update

Der Installer fragt nur beim eigenen Lauf. Jetzt gibt es denselben Weg im Launcher: Einstellungen → Programmordner ausnehmen.

## Änderungen

- Stilles Aktualisieren fragt weiterhin nicht — keine UAC aus dem Hintergrund
- Einstellungen → „Programmordner ausnehmen“ mit Windows-Nachfrage
- Das Ergebnis steht direkt unter dem Knopf
