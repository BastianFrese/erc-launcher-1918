# Spielordner mit gemischten Trennern

Ein von Hand eingetragener Ordner kann als d:/steam\… zurückkommen — das wird jetzt gelesen.

## Änderungen

- Pfad wird mit \ und / gelesen und vereinheitlicht
- Betraf nur Rechner, deren Kopie über einen Schrägstrich eingetragen wurde
- Sonst unverändert
