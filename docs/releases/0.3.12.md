# Mehrere Gäste gleichzeitig

Jeder Gast bekommt vom Host seine eigene Mitgliedsnummer. Vorher meldeten sich alle als dieselbe Person.

## Änderungen

- Der Host vergibt die Nummern beim Prüfruf und behält sie für den Rechner
- Der Launcher startet die Verbindung selbst, mit der vergebenen Nummer
- Eine Nummer wird frei, wenn ein Rechner zehn Minuten still ist
