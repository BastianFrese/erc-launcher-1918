# Dein Name in der Lobby — und im Spiel steht nur noch ERC

Wer beitritt, erscheint unter seinem eigenen Namen. Und der Hinweis beim Start spricht nicht mehr von einem anderen Launcher.

## Änderungen

- Auf der Rennen-Seite trägst du deinen Namen ein — er bleibt gemerkt
- Der Name geht beim Hosten und beim Beitreten mit; leer heißt: der Name aus dem Spiel
- Der Hinweis beim Spielstart heißt jetzt ERC Mod und erklärt die ERC-Lobby
- Der Startbildschirm sagt „Gestartet mit dem ERC Launcher“
