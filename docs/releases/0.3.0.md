# Hält sich selbst aktuell — und sagt dir, was neu ist

Der Launcher holt neue Versionen im Hintergrund und spielt sie ein, wenn gerade nicht gefahren wird.

## Änderungen

- Neue Versionen laden im Hintergrund — du musst nichts anklicken
- Eingespielt wird nur, wenn F1 25 nicht läuft; danach startet der Launcher von selbst neu
- Jede Version wird vorher geprüft, damit unterwegs nichts kaputtgehen kann
- Vor dem Beitritt werden die Mods verglichen — jetzt auch die Launcher-Version
- Diese Hinweise stehen im Paddock und kommen mit jeder Version dazu
