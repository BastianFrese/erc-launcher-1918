# Import findet Mods in Unterordnern

Heruntergeladene Mods liegen oft eine Ebene tiefer — der Launcher sucht jetzt dort und sagt sonst genau, was fehlt.

## Änderungen

- Ordner wählen: die Mod wird auch eine Ebene tiefer gefunden
- Liegen mehrere Mods darin, werden sie zur Auswahl genannt
- Ohne Mod im Ordner kommt ein Satz, der erklärt, wonach gesucht wird
