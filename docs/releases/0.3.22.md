# Spielordner: der Unterbau sucht, nicht der Launcher

Die Suche nimmt jetzt die Kopien, die der Unterbau selbst kennt — Steam-Bibliotheken, EA-App, eingetragene Ordner.

## Änderungen

- „Ordner suchen“ zeigt alle Kopien, die der Unterbau findet
- Ein leeres Feld wird abgefangen und erklärt
- Ein eingetragener Ordner ohne F1_25.exe wird mit klarem Satz abgelehnt
