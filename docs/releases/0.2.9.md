# Mods werden vor dem Beitritt verglichen

Wer andere Mods hat, erfährt es vorher — statt dass die Lobby beim Start abstürzt.

## Änderungen

- Der Host schickt seine Mod-Liste mit, sobald du dich verbindest
- Passt etwas nicht, sagt der Launcher genau was — und startet F1 25 gar nicht erst
- Auch Einstellungen zählen mit, etwa 26 statt 24 Autos
