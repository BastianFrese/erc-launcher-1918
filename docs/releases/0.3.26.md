# Der Installer fragt nach Adminrechten für die Defender-Ausnahme

Nach dem Einrichten fragt Windows, ob der Programmordner von Defender ausgenommen werden soll. Ergebnis steht in defender-ausnahme.log.

## Änderungen

- Windows fragt selbst nach Administratorrechten — ohne Ja passiert nichts
- Nur der Programmordner wird ausgenommen, nichts anderes
- Ist der Defender-Selbstschutz an, verweigert Windows; der Grund steht im Log
- Beim stillen Aktualisieren wird nichts gefragt
