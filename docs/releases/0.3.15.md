# Lobbys zum Anklicken

Wer eine Lobby aufmacht, steht in der Liste. Alle anderen sehen sie und treten mit einem Klick bei — ohne Adresse, ohne Code.

## Änderungen

- Rennen-Seite zeigt die offenen Lobbys mit Namen und Fahrerzahl
- „Lobby eröffnen“ — der eigene Name wird zum Lobbynamen
- „Beitreten“ mit einem Klick
- Läuft über unseren Server, kein offener Port nötig
