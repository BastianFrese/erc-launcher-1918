Was sich seit 1.4.1 geändert hat:

- **Der Name im Spiel ist der Discord-Name.** Wer angemeldet ist, fährt online unter diesem
  Namen — das Spielprofil muss dafür nicht umbenannt werden. Ohne Anmeldung bleibt der
  Profilname.
- **Der Discord-Banner auf der Startseite trägt unser Bild.**
- **Einstellungen → Über → Links:** der Verweis auf die fremde Dokumentation ist raus.
