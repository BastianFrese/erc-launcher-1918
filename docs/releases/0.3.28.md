# Beitritt über den Server geht jetzt

Der Host meldete seine Lobby über einen anderen Port, als er spielte — die Prüfrufe der Gäste liefen ins Leere.

## Änderungen

- Lobby-Meldung nutzt denselben Socket wie die Spieldaten
- Damit kennt der Server die richtige Adresse des Hosts
- Prüfruf, Mod-Abgleich und Beitritt laufen durch
