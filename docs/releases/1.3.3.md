Was sich seit 1.3.2 geändert hat:

- **Beitreten in einen Raum funktioniert wieder.** Beim Wechsel auf den neuen Unterbau sind
  die Aufrufstellen verschwunden, die den Mehrspieler-Teil des Kerns starten — die Dateien
  waren da, wurden aber nie angesprochen. Der Launcher hat einen Raum angelegt, das Spiel
  blieb im Hauptmenü.
- Sonst wie 1.3.2: Update-Knopf ohne Neustart, Prüfung der Spiel-Fassung auf den gemessenen
  Werten.
