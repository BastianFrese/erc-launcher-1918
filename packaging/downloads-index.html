ERC Launcher 0.6.0 · Testfassung

Das Fenster, mit dem wir F1 25 modifiziert starten. Es hält Spiel und Mods aktuell, setzt die Telemetrie und öffnet die Lobby — ohne Konto, ohne offenen Port.

Launcher installieren
Windows, rund 40 MB. Wird für den angemeldeten Benutzer installiert — keine Administratorrechte nötig. Alles Nötige ist darin.
Neu — eine schnellere Grundlage. Der Kern prüft den Spielspeicher nicht mehr bei jedem Zugriff über Windows; das kostete in Ranglisten bis zu 3,5 ms und in Rennen 25–28 ms je Sekunde. Dazu stürzen gleichjährige Seasons nicht mehr beim Start ab, und es passen etwa 76 statt 44 Season-Mods nebeneinander ins Spiel.

Die Lobbys bleiben, wie sie waren — eigener Server, Code zum Weitergeben, kein Konto. Neu ist das Angleichen: fehlt euch eine Mod des Hosts, holt der Launcher sie und schaltet sie ein, statt euch abzuweisen.

So geht es

  1. Herunterladen und ausführen — der Installer richtet alles ein.
  2. F1 25 muss installiert sein (Steam). Sonst wird nichts weiter gebraucht.
  3. Starten, und beim ersten Mal die Bedingungen für das modifizierte Spiel bestätigen.

Zusammen fahren

  1. Beide starten F1 25 und warten im Hauptmenü.
  2. Einer öffnet im Launcher oben Online → Lobby und drückt Lobby erstellen — es erscheint ein Raumcode aus vier Zeichen.
  3. Die anderen tippen den Code unter Einem Raum beitreten ein.
  4. Zurück in der Lobby auf Play — das Spiel öffnet die gemeinsame Sitzung.

Kein Konto, keine Anmeldung, kein Port in der Firewall. Die Lobbyliste kommt von unserem Server. Wer noch nicht beigetreten ist, sieht die offenen Räume unter Lobby mit Code und Fahrerzahl.

Windows wird warnen. Die Datei ist nicht signiert, deshalb meldet sich SmartScreen beim ersten Start („Weitere Informationen“ → „Trotzdem ausführen“). Das ist bei einer Eigenentwicklung normal und kein Fehler.

Wenn etwas klemmt

Im Fenster unten die Konsole aufklappen — dort steht, was zuletzt passiert ist. Ein Bildschirmfoto davon hilft mehr als eine Beschreibung.

Diese Testfassung holt sich keine Aktualisierungen. Wenn es eine neue gibt, sagen wir es hier. Die vorige, ohne Lobbys, liegt weiter daneben: 0.3.30.
