Neu in dieser Fassung

Das Protokoll-Bündel sagt jetzt, was drin ist. Wer Logs schickt, bekommt ein Verzeichnis mit: jede Datei mit Größe, jede ausgelassene mit Grund.

Ladebildschirm: Boxengasse und vier Instrumente, in der Mitte der Fortschritt — voll deckend, das Spiel scheint nicht mehr durch.

Einrichtung: Farben und Wortmarke der ERC-Seite.

So geht es

  1. Herunterladen und ausführen. Der Installer richtet alles für den angemeldeten Benutzer ein — keine Administratorrechte nötig.
  2. F1 25 muss installiert sein (Steam). Sonst wird nichts weiter gebraucht.
  3. Starten und beim ersten Mal die Bedingungen für das modifizierte Spiel bestätigen.

Zusammen fahren

  1. Beide starten F1 25 und bleiben im Hauptmenü.
  2. Einer öffnet im Launcher Online → Lobby und drückt Lobby erstellen — es erscheint ein Raumcode aus vier Zeichen.
  3. Die anderen tippen den Code unter Einem Raum beitreten ein.
  4. Zurück in der Lobby auf Play — das Spiel öffnet die gemeinsame Sitzung.

Gut zu wissen

Windows wird warnen.

Die Datei ist nicht signiert, deshalb meldet sich SmartScreen beim ersten Start („Weitere Informationen" → „Trotzdem ausführen"). Das ist bei einer Eigenentwicklung normal.

Ein eigenes Steam-Konto pro Rechner.

F1 25 erkennt Spieler über die Steam-Kennung. Meldet sich auf zwei Rechnern dasselbe Konto an, hält das Spiel den Gast für den Host — der Beitritt scheitert.

Wenn etwas klemmt

Im Fenster unten die Konsole aufklappen — dort steht, was zuletzt passiert ist. Über Send Logs to the ERC Team geht das Bündel mit einem Klick an uns.

Unterstützen
