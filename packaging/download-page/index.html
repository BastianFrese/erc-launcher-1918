SO GEHT ES

01

Herunterladen und ausführen. Der Installer richtet alles für den angemeldeten Benutzer ein — keine Administratorrechte nötig.

02

F1 25 muss installiert sein (Steam). Sonst wird nichts weiter gebraucht.

03

Starten und beim ersten Mal die Bedingungen für das modifizierte Spiel bestätigen.

ZUSAMMEN FAHREN

01

Beide starten F1 25 und bleiben im Hauptmenü.

02

Einer öffnet im Launcher Online → Lobby und drückt Lobby erstellen — es erscheint ein Raumcode aus vier Zeichen.

03

Die anderen tippen den Code unter Einem Raum beitreten ein und warten, bis der Mod-Stand abgeglichen ist.

04

Zurück in der Lobby auf Play — das Spiel öffnet die gemeinsame Sitzung.

Ein eigenes Steam-Konto pro Rechner. F1 25 erkennt Spieler über die Steam-Kennung. Meldet sich auf zwei Rechnern dasselbe Konto an, hält das Spiel den Gast für den Host — der Beitritt scheitert.
